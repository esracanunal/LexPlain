# LexPlain

Yapay zekâ destekli sözleşme sadeleştirici. Kira, iş ve abonelik sözleşmelerindeki riskli maddeleri bulur ve sade Türkçeyle açıklar.

*SENG 461 – Web Programming with Python and Git* dersi projesidir.

## Teknolojiler
- Backend: Python, FastAPI
- Yapay zekâ: Google Gemini API
- Frontend: HTML, CSS, JavaScript, Bootstrap 5
- Test: pytest

## Ekip
- Esra: API, arayüz tasarımı, belgeler
- Cerenay: metin işleme, KVKK maskeleme, dosya okuma, arayüz etkileşimi
- Emir: yapay zekâ entegrasyonu ve analiz akışı
- Enes: kural motoru, mevzuat bilgi tabanı, risk puanı

## Durum
Geliştirme aşamasında. Kurulum ve kullanım bilgileri eklenecek.
